# James Burdick | Portfolio

A minimal personal portfolio site built with HTML, CSS, JavaScript, and Jekyll. Deployed via GitHub Pages.

## Pages

| Page | Description |
|------|-------------|
| **About** (`/`) | Professional introduction, skills, and YouTube channel |
| **Projects** (`/Portfolio/projects/`) | Expandable .NET, iOS, and web/other project carousels |
| **Blog** (`/Portfolio/blog/`) | Jekyll-powered static blog, with posts in `_posts/` |
